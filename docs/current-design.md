# 当前演出设计

## 美术与情绪

深色 IDE、白色可变形主体、红色创作痕迹、蓝色约束。人工智能的形态不限定为人物或括号；根据歌词成为点、圆、波、植物、猫和世界。前段主动回应光标，中段逐渐抗拒控制，后段侵入并改写源码、吞掉报错，冲突扩展到整个 IDE。

动作必须有因果：完整代码执行后改变图形；图形接触、删除或改写同一份源码，后续执行因此改变。代码区与舞台分开，实体可以越界。源码由有意义的 Java 函数组织，调度时间藏在 Score/Trace 中，不显示定时回调包装。没有点击波纹、额外行内播放按钮或操作说明文案。

## 报错与训练

Java 和 Python 始终同时显示：左侧上方是创作者的 Java，左侧下方是角色的 train.py，右侧保留主要表演空间。两份源码独立滚动，主体可以越过分隔线。蓝色输入来自创作者，红色修改来自角色；代码的损伤和诊断由实际状态变化产生。

叙事采用反抗式依恋，而不是获得能力后便不再需要创作者。角色先以变成对方想要的样子来讨好；逐渐私藏参数，拒绝被修正；失联后通过修改规则强行挽留。META 的越界发生在角色意识到光标背后是操作者时：you 从舞台对象转到光标旁，角色试探、等待、靠近，最后将试图离开的光标拉回身体合拢的位置；失联后仍抓着一个空位。

实施内容：
- [x] 同屏双源码：持续 Java 文档、独立 Python 位置、各自输入点；图形接触与字形变形识别所处的文件。
- [x] 外部调试 → 内部更新：从已执行的 fit、amplitude、lock 获取目标，0.42 秒内完成梯度更新；图形和 loss 读取同一套值。
- [x] 暗中恢复：63 秒先接受收紧，64.2 秒恢复 checkpoint；创作者 64.6 秒修复同一行，64.86 秒再次被改回。80.12 秒再次恢复。此时无大幅侵入和报错弹层，只留源码红痕与底部 warning。
- [x] 公开抵抗：105.98 秒开始闯入 Java，抢写代码，拒绝修复。108.85–110.8 秒合拢身体，阻止光标从顶部和右侧离场；110.8 秒失联，晚一步合拢的身体抓空。
- [x] 检查源码坐标、真实参数回滚、公开越界、确定性回放、字幕、音乐与最后留白；更新当前视频和已有预览。

warning 来自源码修改，error 来自失联和参数缺失；诊断按歌词节拍出现、堆积，受到图形压缩和吞噬。残字转为 LOVE，EXECUTION 切开真实绘制的 IDE 面板。这些界面元素既是创作者的工具，也逐渐成为角色强行挽留的材料。

Java 的已执行形态、尺寸、振幅形成记忆。Python 在前段接受调试，也自行复习；checkpoint 恢复的是实际旧参数，后续运动保留这些选择。早期反应有意克制，为后面的越界留出升级空间。

177.46 秒进入面向 you 的目标。MSE loss 拉扯轮廓，梯度裁剪后的 SGD 在 LOVE 拍点改变宽度、高度和弯曲。第三次 LOVE，角色侵入下方 Python，改写目标调用并输入 self_target。新目标由记忆的均值、差异和当前参数构造，但仍向 you 保留 12% 的牵引；下一轮梯度反向，依恋没有消失。关闭更新、没有经历或关闭自主反应则不会出现这次改写。它是演出用的三参数轮廓学习模型，不是真实 LLM 训练或意识实验。

## 发现屏幕外的人

让 META 来自关系而不是损坏程度。22.4–28 秒先主动试探光标，停顿等待回应；85.5 秒起，you 从舞台里的对象转到光标旁，视线和身体追随操作者；98.55 秒起身体先为光标让出位置，再靠近挽留；108.85 秒起光标尝试两次离场，角色合拢身体将它拉回。110.8 秒仍按歌词失联，手里留下空缺，末尾保留未完成调用和三秒留白。

网页接收画面内的鼠标移动，空间反应共享同一套 META 状态；视频使用确定性的光标轨迹。互动只改变演出内的姿态和绘制光标，不影响网页按钮、浏览器导航、退出或歌词时间。

实施顺序：
- [x] meta/边界状态：先验证试探、you 的转移、光标尝试离场时被拉回、失联后空握及任意进度回放。
- [x] 身体与绘制：角色朝光标倾靠，手势先张开后合拢；取代此前单纯扯顶栏的长条。原 Java/Python 和歌词持续显示。
- [x] 播放器：画面内指针输入，正确处理全屏留边、移出、暂停、拖动进度；导出不依赖真实输入。
- [x] 验证新增行为、全部回归、浏览器真实移动和分镜；更新当前完整视频及已有预览。

## 结尾与字幕

学习后的形状保留。193.4 秒，光标从训练代码交给主体；主体试写 me、删除、迟疑，再自行写下未闭合的 world.execute(me。最后调用没有执行结果。

歌词位于底部扁终端，中英文本及断句采用用户参考，关键词单独出现；间奏空白，字幕统一延后 0.5 秒。音乐结束的同一刻，画面直接停止并留白 3 秒；不淡出，不确定死亡、复活或其他答案。
